# QuickSave Chrome Extension

QuickSave is a simple Chrome extension that lets you save webpages to a personal reading list and open or remove them anytime.

## How to Use

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select this project folder.
5. Open the QuickSave extension, visit a webpage, and click **Save Current Page**.
6. Use the saved links to reopen pages or click **Remove** to delete one.
