# QuickSave Chrome Extension

QuickSave is a Chrome extension for saving webpages in collections, so they are easy to find and read later.

## Features

- Save the current webpage
- Organize pages into collections
- Search saved pages
- Move or remove saved pages

## How to Use

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select this project folder.
5. Click the QuickSave extension icon and optionally choose or create a collection.
6. Visit a webpage and click **Save Page**.
7. Use the search bar to find pages, select a collection to move them, or click **Remove** to delete one.
